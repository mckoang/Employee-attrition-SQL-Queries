# 📘 SQL Employee_Attrition Queries – PostgreSQL

This repository contains a collection of SQL queries written in PostgreSQL as part of my data analysis and database learning journey. These queries are designed to explore various real-world datasets and cover a wide range of SQL concepts, including:

- Filtering and aggregating data  
- Grouping and ordering results  
- Using subqueries  
- Calculating attrition rates, averages, and distributions  
- Rounding values and formatting outputs  
- Exploring employee-related metrics and patterns  

## 🗂️ File Description

- `practice_queries.sql`  
  This file contains structured SQL queries that analyze HR/employee data. Topics include:
  - Total employee counts  
  - Gender distribution  
  - Department-wise summaries  
  - Attrition rate by gender  
  - Training, education, and income analysis  
  - Top salaries and more  

## 🧠 Purpose

The goal of this project is to:
- Improve SQL proficiency using PostgreSQL  
- Answer practical business questions using data  
- Build a portfolio of analytical solutions
